# Rishabh-Analytics-Dashboard

Features
📈 Overall Attrition Rate & KPIs
🏢 Department-wise Attrition Analysis
👥 Employee Demographics (Age, Gender, Education)
💼 Job Role & Salary Insights
📅 Years at Company & Experience Trends
🎯 Interactive Filters (Slicers) for deep analysis
📊 Clean and professional dashboard design
🧠 Objectives
Identify major causes of employee attrition
Analyze trends across departments and job roles
Understand the impact of salary and experience
Provide actionable insights for HR strategies
🛠️ Tech Stack
Tool: Microsoft Power BI
Language (for preprocessing): Python (Pandas, NumPy) (optional)
Dataset: HR Employee Attrition Dataset (CSV/Excel)
